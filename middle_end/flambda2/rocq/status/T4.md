- The parameter is `join_scoped_envs : meet_expanded_head -> Scope.t ->
  Meet_env.t -> Typing_env.t -> list Typing_env.t -> option

  inside. `None` is a fatal error or no fuel.

  The scoped environments are kinded; the result is kinded (T5's
  `join_keeps_kinded`, whose premises `scoped_env_of` gives).
- The default strategy (`Dfs`) only.
- T5's join calls my `Meet_env.add_variable_definition`,
  `add_env_extension` (the one that is not strict), `make_bottom` and
  `enter_scope`.
- T4-1 is read the same way by both.

  type "`Is_int` of `x`" where `x` may have no value in the run, so
  the n-way join may not have J1. Weakening the conclusion (such `r`

  the valuation cannot be supplied after a join that imports from a
